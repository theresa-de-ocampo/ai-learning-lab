# Getting Started
Install the dependencies and run the server:

```
npm install
npm start
```

Then open:

```
http://localhost:3000/
```

To ask Ollama a question:

```
http://localhost:3000/?question=Why%20is%20the%20sky%20blue%3F
```

Make sure Ollama is running locally and that the `mistral` model is available:

```
ollama pull mistral
```
